# English pronunciation practice log

Copy this template into a private note. Keep personal recordings and account details out of public GitHub issues or pull requests.

## Session template

- Date:
- Sentence or phrase:
- Source of sentence/reference audio:
- One focus for this session:
- What I heard in my first recording:
- Recording conditions or problems:
- Tool feedback, if used:
- One change I tried:
- What I heard in the second recording:
- What a listener heard, if someone helped:
- Focus for next time:

If you include a score, record the tool and conditions too. A number alone is not enough to compare progress across different sentences, microphones, or services.

## Example — illustrative, not a real user result

- Sentence: “Please send the file today.”
- Focus: Keep the ending of “send” audible.
- First recording: I rushed from “send” into “the.”
- Conditions: Quiet room; same microphone for both recordings.
- Change: Rehearsed “send the file,” then recorded the full sentence.
- Second recording: The ending was easier for me to hear.
- Next time: Keep the phrase smooth without making every word separate.

This example shows how to write a useful note. It is not a testimonial, experiment, or evidence of a product outcome.
